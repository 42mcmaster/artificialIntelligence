Select ALL correct options for each. No partial credit — just like the exam.

**1.** Which THREE techniques transform **text** into features for a model? (Choose 3)

   - [ ] A. Bag-of-Words
   - [ ] B. TF-IDF
   - [ ] C. Word Embeddings
   - [ ] D. Grayscale pixel values
   - [ ] E. Min-max scaling

**2.** Which TWO problems are best solved with **supervised** learning? (Choose 2)

   - [ ] A. Classify a web page as kid-friendly or adult
   - [ ] B. Predict next year's sales from labeled history
   - [ ] C. Group customers into unknown segments
   - [ ] D. Detect novel anomalies with no labels

**3.** Which THREE are signs of **poor data quality** you should fix before modeling? (Choose 3)

   - [ ] A. Missing values (NaN / None / blank)
   - [ ] B. Scrambled or incomprehensible values
   - [ ] C. Stale / out-of-date records
   - [ ] D. A well-labeled target column
   - [ ] E. Consistent date formats

**4.** Which TWO are true of model **hyperparameters**? (Choose 2)

   - [ ] A. They are set by the practitioner before training
   - [ ] B. They can be chosen using heuristics or search
   - [ ] C. They are learned automatically from the data
   - [ ] D. They are the model's output predictions

**5.** Which THREE are common **challenges when deploying** an AI product? (Choose 3)

   - [ ] A. User challenges (adoption, training)
   - [ ] B. Data discrepancies (production vs. training data)
   - [ ] C. System integration issues
   - [ ] D. The model achieving 100% training accuracy

**6.** Which TWO actions **maximize business impact** of an ML project? (Choose 2)

   - [ ] A. Deploy an MVP quickly and iterate
   - [ ] B. Translate business goals into measurable success criteria
   - [ ] C. Maximize model complexity for its own sake
   - [ ] D. Skip stakeholder input to move faster

**7.** Which THREE belong in **responsible / trustworthy AI** practice? (Choose 3)

   - [ ] A. Check training data for sources of bias
   - [ ] B. Document data and modeling decisions
   - [ ] C. Provide transparency about how the model is used
   - [ ] D. Hide the model's limitations from users

**8.** Which TWO describe a **feedback loop** in a deployed AI system? (Choose 2)

   - [ ] A. Model predictions are reviewed and fed back as new labels
   - [ ] B. New labeled data updates/retrains the model over time
   - [ ] C. The model never changes after deployment
   - [ ] D. Users are prevented from correcting outputs
