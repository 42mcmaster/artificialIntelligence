# AI Cert Drill: Choose All That Apply — ANSWER KEY

**INSTRUCTOR / SELF-CHECK KEY**

---

**1.** Which THREE techniques transform **text** into features for a model? (Choose 3)  
**Correct: A, B, C** — Bag-of-Words, TF-IDF, Word Embeddings  
*Bag-of-Words, TF-IDF, and Word Embeddings turn text into numbers. Grayscale pixels are for images; min-max scaling is for numeric features.*

**2.** Which TWO problems are best solved with **supervised** learning? (Choose 2)  
**Correct: A, B** — Classify a web page as kid-friendly or adult, Predict next year's sales from labeled history  
*Supervised learning needs labeled examples (classification, regression). Grouping into unknown segments is clustering (unsupervised).*

**3.** Which THREE are signs of **poor data quality** you should fix before modeling? (Choose 3)  
**Correct: A, B, C** — Missing values (NaN / None / blank), Scrambled or incomprehensible values, Stale / out-of-date records  
*Missingness, scrambled values, and staleness all hurt quality. A good target and consistent formats are what you WANT.*

**4.** Which TWO are true of model **hyperparameters**? (Choose 2)  
**Correct: A, B** — They are set by the practitioner before training, They can be chosen using heuristics or search  
*Hyperparameters are set before training (and tuned via search). Parameters/weights are learned from data; predictions are outputs.*

**5.** Which THREE are common **challenges when deploying** an AI product? (Choose 3)  
**Correct: A, B, C** — User challenges (adoption, training), Data discrepancies (production vs. training data), System integration issues  
*Deployment challenges are people, data, and integration. 100% training accuracy is actually a red flag (overfitting), not a deployment challenge.*

**6.** Which TWO actions **maximize business impact** of an ML project? (Choose 2)  
**Correct: A, B** — Deploy an MVP quickly and iterate, Translate business goals into measurable success criteria  
*Ship an MVP and tie it to measurable business KPIs. Complexity-for-its-own-sake and skipping stakeholders both reduce impact.*

**7.** Which THREE belong in **responsible / trustworthy AI** practice? (Choose 3)  
**Correct: A, B, C** — Check training data for sources of bias, Document data and modeling decisions, Provide transparency about how the model is used  
*Bias checks, documentation, and transparency are responsible-AI staples. Hiding limitations is the opposite.*

**8.** Which TWO describe a **feedback loop** in a deployed AI system? (Choose 2)  
**Correct: A, B** — Model predictions are reviewed and fed back as new labels, New labeled data updates/retrains the model over time  
*A feedback loop returns real-world outcomes as new labels to keep the model current. A static model with no correction is the opposite.*
