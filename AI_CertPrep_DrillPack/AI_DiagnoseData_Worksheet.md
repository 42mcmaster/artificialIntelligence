## Part A — Spot the Data-Quality Issue

A row from a customer table:

```
  customer_id | age | country | amount_usd | signup_date
  C001        | 34  | Unknown | NaN        | 2026-13-02
```
For each column, name the problem (or 'ok'):

1. `age` = 34 → `____`
2. `country` = Unknown → `____`
3. `amount_usd` = NaN → `____`
4. `signup_date` = 2026-13-02 → `____`

## Part B — Variable / Feature Types

Label each as **numerical (continuous)**, **numerical (discrete/count)**, **categorical**, or **ordinal**:

5. Temperature in °F → `____`
6. Eye color (brown/blue/green) → `____`
7. Number of children → `____`
8. T-shirt size (S/M/L/XL) → `____`

## Part C — Classify the AI Problem

Name the problem type — **regression**, **classification**, or **clustering**:

9. Predict tomorrow's temperature (a number) → `____`
10. Decide if an email is spam or not → `____`
11. Group shoppers into segments you haven't defined yet → `____`
12. Predict a house's sale price → `____`
13. Sort photos into 'cat' vs 'dog' → `____`
