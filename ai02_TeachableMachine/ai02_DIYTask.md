# Lesson 02 DIY Challenge — Teachable Machine
**Artificial Intelligence — Medina County Career Center**

Pick **one** and write a short (half-page) report with screenshots.

## Option A — Three-class classifier
Build a model with **three** classes (e.g., three animals, or rock/paper/scissors hand signs via
webcam). Test it and report: does adding a third class make it more or less accurate? Why?

## Option B — Fool the model
Train a two-class model, then deliberately find images that **fool** it. Collect 3 images it gets
wrong and write one sentence per image explaining *why* you think it failed (angle, lighting,
background, look-alike, too few examples...).

## Option C — Bias hunt
Train a model but give one class only **one type** of example (e.g., only cats that are orange).
Then test with a very different example of that class (a black cat). What happens? Connect this to
the idea of **biased training data** (preview of ai11 Ethics).

**Every option must end with:** one paragraph on how training data affected your results.
